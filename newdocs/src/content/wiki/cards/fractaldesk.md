- **Path:** `apps/fractaldesk`
- **What:** Not a code app — a docs reference bundle for **Open WebUI**. Carries `AGENTS.md`, `llms.txt`, `llms-full.txt`.
- **Agent-readable docs access:**
  - Discover pages: `https://docs.openwebui.com/sitemap.xml`
  - Search: `https://docs.openwebui.com/api/search?q=YOUR_QUERY`
  - Page variants: append `.md` (Markdown) or `.txt` (plain text)
  - Compact index: `https://docs.openwebui.com/llms.txt`
- **Citation rule:** cite the canonical HTML URL, not the `.md`/`.txt`/search-API URL.
