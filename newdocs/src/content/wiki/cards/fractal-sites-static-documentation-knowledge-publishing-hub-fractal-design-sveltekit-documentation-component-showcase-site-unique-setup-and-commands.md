Project scaffolded with `sv create --template minimal --types ts --add prettier eslint sveltekit-adapter="adapter:vercel" mdsvex --install pnpm fractaldesign`. Development runs via `pnpm dev` (or `npm run dev`, build via `vite build`, preview via `vite preview`, type-check via `svelte-check --tsconfig ./tsconfig.json`, lint/format via `prettier --check . && eslint .` and `prettier --write .` respectively. Requires `pnpm prepare` (svelte-kit sync) before type checking.
