Run `npm run build` which invokes `vite build && npm run prepack`; `prepack` runs `svelte-kit sync && svelte-package && publint` to produce the distributable `dist/`. Icon components are regenerated by running `node scripts/generate.js`, which scans `static/svg/<set>-<variant>/` directories and writes `src/lib/<set>/icons/*.svelte` plus a barrel `index.ts`. Development server: `npm run dev`.
