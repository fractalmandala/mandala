SvelteKit 2 + Vite 8 with mdsvex for Markdown-as-pages, Sass preprocessing, and the `fractals-styler` design system plugin; deployed via `@sveltejs/adapter-vercel` on Node.js 24. The embedded SKAA server uses Python with the `mcp` (FastMCP) library, PyYAML for probe definitions, and SQLite per-project storage (`.skaa/smriti.db`.
