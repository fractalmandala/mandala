Install via `npx fractal-agentic install --target=<host>` or host-specific marketplace commands; set `FRACTAL_AGENTIC_ROOT` to this directory; run `sh scripts/install-agents.sh [--target-dir <path>] [--check]` to deploy the three TOML custom-agent templates without modifying host config; verify with `sh scripts/check-armory.sh` and `sh scripts/verify.sh`; resolve the active root with `sh scripts/resolve-plugin-root.sh`.
