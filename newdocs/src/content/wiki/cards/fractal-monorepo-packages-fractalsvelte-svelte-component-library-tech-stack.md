Svelte 5 with runes mode enforced via Vite compiler options, SvelteKit 2, Tailwind CSS v4, bits-ui v2 as the headless primitive layer, Sass for styling, mdsvex for markdown docs, Shiki for syntax highlighting, and sveltekit-superforms/formsnap for form handling. Published as an ESM package with explicit `exports` entries per component and peer dependency on `svelte ^5.0.0`.
