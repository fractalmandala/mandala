Skills are primarily Markdown-driven prompts consumed by the ECC/Claude Code agent runtime; many embed Python scripts (`*.py`, Node/TypeScript tools (`*.mjs`, `*.cjs`, shell scripts (`*.sh`, YAML agent configs, and JSON schemas. Some skills ship full applications (e.g. `impeccable` has a live browser server, `memclaw` includes a Python MCP server and FastAPI backend, `skill-comply` uses a `pyproject.toml` test harness).
