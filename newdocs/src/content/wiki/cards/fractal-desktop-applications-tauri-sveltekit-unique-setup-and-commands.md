Each app is self-contained: run `pnpm dev` (or `npm run dev` for the frontend, `pnpm tauri dev` to launch the Tauri desktop window, and `pnpm verify` (Fracta) or `pnpm lint` (Shradhapp) for checks. Fracta also exposes Playwright visual tests and separate test scripts for markdown, agent prompts, JSON trees, and motion.
