title: "coding_conventions"
description: ""
---

- Each school's note follows a fixed seven-line template: an H1 title line, then one `Key: Yes/No` line per epistemic mean in the order Analogy, Inference, Perception, Postulation, Testimony.
- Filenames combine the school name with a 32-character hex ID suffix (e.g. `Mimamsa 3f9c0fb733044483ab4dc530867ca95e.md`) to match Notion's record identifiers.
- CSV exports use a header row of `Property,Perception,Inference,Testimony,Analogy,Postulation` with one row per school and Yes/No values aligned to the columns.
