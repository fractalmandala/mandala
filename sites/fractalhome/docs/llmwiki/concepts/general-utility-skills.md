Fractal Agentic keeps a **general utility armory** (AGENTS §0.1a) for work that is useful in any session without selecting a domain boss:

- academic-research
- content-research-writer
- docs-writer
- human-writing
- file-organizer
- layout-capture
- visual-design

Skills are **host- and model-agnostic** (no Claude/Codex-only wording). Credits: **ASI** → https://github.com/plurigrid/asi. Related: [[Domain Bosses Armory]], [[Credits Attribution]], [[Fractal Agentic Plugin]].
