Repository portfolio management keeps a lightweight local record of each collected tool and periodically compares the collection as a whole. Notes should distinguish repository-described purpose from evidence of local use, label uncertainty honestly, and ground duplicate or maintenance-risk claims in actual functions, references, and commit history. Read-only manual passes should prove value before automation is scheduled. Related: [[LLM-Maintained Wiki]] and [[Context Engineering]].
