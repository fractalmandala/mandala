A compositional utility design system using indented SASS and predefined pixel step tokens (4, 8, 16, 24, 32, 48, 64, 80). Enforces a clear container hierarchy (`shell` -> `workspace` -> `viewport-page`) with zero in-component CSS blocks and single-tab indentation. Related: [[Frontend Interaction Patterns]] and [[SvelteKit Development]].

**Site routes:** homepage promotional front door vs docs hub; dark-mode flash on refresh under investigation; styler language extends to docs/bosses/skills/agents/commands/wiki. Source: [[Plugin Site Homepage Theme and Docs Route Styling (Source Summary)]].
