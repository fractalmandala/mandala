- Every Svelte package declares `peerDependencies: { svelte: "^5.0.0" }` and builds against Svelte 5 runes.
- Package entry points use the standard `svelte`/`types`/`exports` triple pointing into `./dist`, with `sideEffects` listing CSS/SASS files.
- `prepack` scripts consistently run `svelte-kit sync && svelte-package && publint` before publishing.
- Component directories follow a flat `components/<name>/index.js` structure with co-located `.d.ts` types generated by svelte-package.
- Build tooling uses Vite with `@sveltejs/vite-plugin-svelte` and `@sveltejs/package` rather than custom rollup configs.
