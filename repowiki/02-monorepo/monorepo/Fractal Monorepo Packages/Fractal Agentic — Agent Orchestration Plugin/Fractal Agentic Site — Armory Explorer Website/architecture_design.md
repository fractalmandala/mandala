Built on SvelteKit with Vite, the site is a static/prerendered explorer whose source of truth lives in the sibling `plugin/` package. Content discovery uses `import.meta.glob` with raw imports to load markdown files from `plugin/skills/*/SKILL.md`, `plugin/agents/*.md`, `plugin/commands/*.md`, and `plugin/docs/**` at build time; entries are parsed via frontmatter + markdown helpers in `src/lib/content/parse.ts` and cached in module-level variables (`_skills`, `_agents`, etc.) for repeated access. Route handlers under `src/routes/{agents,bosses,commands,skills,docs}/[slug]/+page.server.ts` use SvelteKit's `EntryGenerator` to prerender every armory item, returning structured data plus server-rendered HTML via `renderMarkdown`. A root `+layout.server.ts` injects shared stats, sidebar navigation, and a global search index into every page. UI components live in `src/lib/comps/` and are re-exported through `src/lib/index.ts`; theme, styles, icons, and shared types are centralized under `src/lib/theme.ts`, `src/lib/styles/`, `src/lib/icons/`, and `src/lib/types.ts`. The adapter is `@sveltejs/adapter-vercel` with Node 24 runtime pinned; mdsvex preprocesses `.svx`/`.md` extensions, and `fractals-styler` provides design tokens.
