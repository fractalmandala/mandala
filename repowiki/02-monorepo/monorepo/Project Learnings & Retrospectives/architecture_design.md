Flat collection of Markdown learning articles under docs/learnings/, each written in a consistent YAML frontmatter + narrative structure (title, description, category, date) followed by sections: What happened, What I learned, What not to do, and Self-evaluation with Accuracy/Completeness/Clarity/Actionability/Conciseness ratings. INDEX.md serves as the single entry point linking all articles. There is no code or build system — this is pure documentation consumed by the project's knowledge base.
