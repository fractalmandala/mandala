The site is a Blume static site generator project rooted at `sites/fractalhome/`. Content lives under `content/` and `docs/` as Markdown files organized into topic directories, each with an `INDEX.md` serving as the section entry. Blume's configuration in `blume.config.ts` declares frontmatter schema via Zod, navigation tabs (`Home`, `Tags`), sidebar grouping, and theme fonts. Custom behavior is layered through three extension points: `components.ts` registers Astro components (`Logo.astro`, `PageHeader.astro`) to override Blume's default layout pieces; `wiki-links.mjs` implements a custom Blume integration that walks the docs tree, builds a title-to-route map, and patches Astro's markdown processor to rewrite `[[page]]` wiki links into `<a>` tags at render time; and `pages/tags/` provides two Astro pages — `index.astro` for the tag cloud and `[tag].astro` for per-tag filtered lists — both querying `getCollection('docs')` and `blume:data` routes to build their views. The dependency direction is one-way: content → Blume config → Astro pages/components, with no server-side logic beyond static pre-rendering.
