Built as a SvelteKit 2 application deployed via the Vercel adapter (nodejs24.x runtime). Content lives under `src/content/<Bank>/wiki/` and `src/content/<Bank>/raw/`, each bank containing an `INDEX.md` frontmatter entry plus per-topic `.md` files. A Node script (`scripts/sync-banks.mjs`) copies Markdown from an external vault (`BANK_VAULT_PATH`, default `/Users/amrit/100cabinet/10wiki`) into `src/content`, driven by `src/lib/data/routes-config.json` which maps each bank name to its source paths. Routing follows SvelteKit conventions: one top-level route folder per bank (e.g. `routes/archaeology/`, `routes/civilization/`) with a list page (`+page.svelte`), a parameterized post page (`[post]/+page.svelte`), and optional graph pages. The global layout (`routes/+layout.ts`) loads all banks in parallel via `listPosts()` against the routes config, feeding a shared `Shell` component used by every page. mdsvex preprocesses `.md` files into Svelte components; FlexSearch powers client-side search, Graphology + Sigma render force-atlas2 network graphs for select banks, and gray-matter parses frontmatter. Static assets (fonts, images, prebuilt `graph.json` files) sit under `static/`.
