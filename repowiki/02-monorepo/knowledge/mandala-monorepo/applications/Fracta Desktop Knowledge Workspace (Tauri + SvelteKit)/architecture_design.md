Two-layer application: a SvelteKit frontend under `src/` (SPA, prerendered layout, static adapter) communicates with a Rust Tauri backend under `src-tauri/`. The Rust side exposes typed commands via `#[tauri::command]` functions in `lib.rs`, which dispatch to domain modules (`vault.rs` for `.md` entry CRUD, `workspace.rs` for recursive file operations, `search.rs` for indexing/search, `autotag.rs` for clipboard-driven tagging rules, `gguf.rs` for a local llama-server engine, and `frontmatter.rs` for YAML frontmatter parsing). State is shared through Tauri's `State<T>` (Vault, AutoTag, GgufEngine) initialized in the builder. The frontend calls these commands through a single TypeScript IPC facade in `src/lib/ipc.ts` that mirrors every Rust command with a matching `invoke(...)` call and TypeScript interfaces. Filesystem access is strictly scoped: vault paths are canonicalized and entry ids are validated against path traversal; workspace operations use a `resolve()` helper that rejects `..`, symlinks outside root, and absolute paths. A `notify` watcher emits `workspace://changed` events so the UI stays in sync without polling. The app bundles as a Tauri binary targeting macOS, Windows, Linux, Android, and iOS (via `cfg` gates), with platform-specific dependencies like `objc2-*` on macOS for clipboard source detection.
