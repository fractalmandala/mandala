# LLM Wiki — Continuous knowledge base

File-first, local, **LLM-maintained** wiki. Humans curate sources and ask questions;
the agent writes and maintains `wiki/`. Never block product work if the vault is unset.

Canonical policy for soft failure: [docs/progression.md](../../docs/progression.md).  
Vault structure and page rules: [references/wiki-schema.md](references/wiki-schema.md).  
Config resolve: [references/config.md](references/config.md).

## Architecture

```text
$FRACTAL_WIKI_ROOT/
  AGENTS.md                 # librarian rules (generated by wiki-init)
  .fractal-wiki.json        # path metadata
  raw/                      # immutable sources + fractal episodes
    assets/
    fractal/                # orchestrate/boss capture (append-only)
  wiki/
    index.md                # catalog (uses page description)
    log.md                  # append-only ops log
    sources/  entities/  concepts/  synthesis/
  output/                   # query artifacts, reports
```

Three layers:

| Layer | Role | Who writes |
|---|---|---|
| **raw/** | Source of truth; never rewrite | Human (clips) + agent (fractal episodes only under `raw/fractal/`) |
| **wiki/** | Compiled, interlinked knowledge | Agent only |
| **output/** | Generated answers / decks / charts | Agent |

## When to use which command

| Command | When |
|---|---|
| `/wiki-init` | First setup — choose path, scaffold vault, write config |
| `/wiki-status` | Show resolved root, counts, last log entries |
| `/wiki-capture` | Manual episode capture (or after orchestrate if auto-capture on) |
| `/wiki-ingest` | Process unprocessed files in `raw/` into wiki pages |
| `/wiki-query` | Answer questions from wiki (cite `[[wikilinks]]`) |
| `/wiki-lint` | Health check after ~10 ingests or monthly |

## Session bootstrap (soft)

1. Resolve vault root (see [config.md](references/config.md)).
2. If missing: state once *“LLM wiki not configured; continuing without wiki.”* Offer `/wiki-init`. **Do not stop product work.**
3. If present: prefer wiki for “what do we know / prior decisions” questions; read `wiki/index.md` first.

## Fractal capture (orchestrate / bosses)

**Not every skill.** Default capture triggers:

- End of **`/orchestrate`** (ship | fix-first | rethink)
- Optional: boss handoff, commitment-boundary, santa-loop ship

Write an append-only episode under `raw/fractal/` (see schema). Full multi-page wiki update only via `/wiki-ingest` (or user asks to crystallize the episode).

On capture failure: warn once; **never fail the orchestrate delivery**.

## Frontmatter (required)

Every wiki page **and** every fractal episode must include:

- `title`
- **`description`** — one line, ≤120 chars (index + search snippet)
- `created`, `updated` (YYYY-MM-DD)
- `tags` (array)

See [wiki-schema.md](references/wiki-schema.md) for full fields.
