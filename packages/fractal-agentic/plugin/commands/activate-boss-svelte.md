# Activate Boss — Svelte

```text
/activate-boss-svelte
```

1. Read the [startup router](../AGENTS.md) for authority, stop-reading rules,
   stack/surface detection, handoffs, and non-blocking policy.
2. Read the [Svelte Boss playbook](../docs/bosses/svelte/) —
   `docs/bosses/svelte/INDEX.md` — in full.
3. Make Svelte the active boss and do **not** load another boss playbook until a
   documented handoff requires it.
4. For non-trivial delivery work, run [`/orchestrate`](../commands/orchestrate.md) and load the
   [runtime](../skills/boss-orchestration/SKILL.md) it names.

Svelte owns the runes, SvelteKit, indented-SASS, and port-component contract. Handoff
polish to Design, ship gates to Code, and net-new scaffolds to Creator.
