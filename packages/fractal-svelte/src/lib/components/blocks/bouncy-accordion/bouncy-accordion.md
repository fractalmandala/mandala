# BouncyAccordion Layout Capture

**Source component:** `bouncy-accordion.svelte`  
**Sibling styles:** `bouncy-accordion.sass`

## Diagram 1 — UI architecture and layout flow

```mermaid
graph TD
	BA_ROOT["`**bouncy accordion**<br/>*(100% width; vertical flex; space-1 gap)*`"]
	BA_LOOP["`**accordion items**<br/>*({#each} keyed by id; bordered cards; overflow hidden; open items gain vertical margin)*`"]
	BA_TRIGGER["`**trigger row**<br/>*(100% width flex; min-height 3.375rem; space-3 gap; horizontal space-4 padding)*`"]
	BA_ICON["`**item icon**<br/>*(optional snippet; inline-flex)*`"]
	BA_TITLE["`**title**<br/>*(flex: 1; occupies remaining row width)*`"]
	BA_CHEVRON["`**chevron**<br/>*(1rem square; rotates when expanded)*`"]
	BA_PANEL["`**panel**<br/>*(open-only via hidden attribute; overflow hidden)*`"]
	BA_CONTENT["`**content**<br/>*(space-4 side/bottom padding; content snippet or description)*`"]
	BA_ROOT --> BA_LOOP --> BA_TRIGGER
	BA_TRIGGER --> BA_ICON
	BA_TRIGGER --> BA_TITLE
	BA_TRIGGER --> BA_CHEVRON
	BA_LOOP --> BA_PANEL --> BA_CONTENT
```

## Layout breakdown

- `BA_ROOT` / `BA_ACCORDION_BOX` establishes a full-width vertical stack; `BA_LOOP` / `BA_ITEM_BOX` represents every keyed item generated by `{#each}`.
- `BA_TRIGGER` is a horizontal flex boundary containing the optional icon, flexible title, and fixed chevron in that order.
- `BA_PANEL` remains the content boundary but is hidden when closed; `BA_CONTENT` chooses between the item snippet and description text.
- Open-state margins alter spacing around an item. No breakpoint-specific, sticky, fixed, grid, or scrolling layout is defined.
