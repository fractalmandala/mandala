# Parity Matrix — fractalknow (Tauri + Svelte 5) vs open-knowledge (Electron + React)

Audit date: 2026-07-31 · Auditor: Agent D (tasks T022 + T023)
Reference (read-only): `open-knowledge-main/packages/` (`app/src`, `core`, `server`, `cli`, `desktop`, `plugin`, `native-config`)
Replica: `src/` (SvelteKit) + `src-tauri/src/` (Rust)

Status legend: **parity** = functionally equivalent · **partial** = surface exists but materially reduced · **missing** = no equivalent · **intentionally-dropped** = declared out of scope by owner decision dated 2026-07-31 (see below).

Note on scale: reference `packages/app/src` has \~1,000+ source files (excluding tests); the replica has \~70. Most reference UI below therefore maps to a small set of shell components.

## Owner scope decisions — 2026-07-31

The owner declared the following subsystems **intentionally-dropped** for the local-only v1:

- **Orama full-text search** — dropped; sidebar name/path filter is the accepted search surface.
- **MCP server** (and its consent/install flows) — dropped.
- **Git-backed sync** (sync engine, worktrees, publish, clone execution) — deferred/dropped; local-only v1.
- **CLI and web-UI launcher** — dropped; Tauri desktop app only.
- **Backend server** (`packages/server` equivalent) — dropped, **except** local agent session/history management, which is retained as in-scope and will be built locally.
