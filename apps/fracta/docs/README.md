# Fracta documentation

Fracta is a local-first desktop knowledge workspace built with Tauri, SvelteKit, and Rust. Your chosen project folder remains the source of truth.

- [User guide](./USER_GUIDE.md) — workspaces, documents, data files, search, Ask, and export.
- [Developer guide](./DEVELOPER_GUIDE.md) — architecture, local setup, commands, testing, and extension points.

## Support boundaries

Markdown, MDX, TXT, CSV, TSV, and JSON are editable. PDF and DOCX are intentionally read-only and are extracted locally for viewing, search, and Ask context. Other file types are safe attachments that can be revealed or opened with the operating system.
